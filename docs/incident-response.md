# Incident response

1. Detect. Review application alerts, authentication failures, unusual rate-limit events, suspicious uploads and provider failures.

2. Contain. Disable affected endpoint or deployment path. Invalidate active admin sessions when compromise is suspected.

3. Revoke. Rotate APP_SECRET, SMTP credentials, CAPTCHA secrets, storage credentials and other affected tokens.

4. Preserve. Keep relevant audit logs and deployment identifiers while avoiding unnecessary personal data.

5. Recover. Redeploy a verified build, restore trusted data, and test health, authentication, forms and headers.

6. Communicate. The designated company owner and legal/privacy contact decide notification obligations.

7. Learn. Record root cause, affected controls, remediation, verification date and follow-up owner.
